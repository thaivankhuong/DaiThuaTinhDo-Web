# Đại Thừa Tịnh Độ — Lộ trình học Kinh Vô Lượng Thọ (bản web)

Trang web tĩnh: lộ trình học 374 tập giảng Kinh Vô Lượng Thọ của Hòa thượng Tịnh Không, kèm nguyên văn từng tập, trích dẫn và kinh gốc 48 phẩm có đối chiếu tập ↔ phẩm.

**Xem trực tuyến:** https://thaivankhuong.github.io/DaiThuaTinhDo-Web/

## Nguồn & ghi công
- Bài giảng: Hòa thượng Tịnh Không, *Kinh Đại Thừa Vô Lượng Thọ Trang Nghiêm Thanh Tịnh Bình Đẳng Giác* (374 tập).
- Bản Việt dịch các tập giảng: Pháp Âm Tuệ Sáng — https://ph.tinhtong.vn
- Kinh văn 48 phẩm: langnghiem.com — dịch giả Vọng Tây cư sĩ; Thích Đức Niệm & Cư sĩ Minh Chánh.

Mọi nội dung thuộc về các tác giả, dịch giả và nguồn gốc nêu trên; trang này chỉ sắp xếp lại để tiện học tập, phi thương mại.

## Ghi chú
Repo này chỉ chứa bản đã build (`index.html` + `data/`). Mã nguồn, script và dữ liệu gốc nằm ở repo dự án DaiThuaTinhDo (riêng tư).
